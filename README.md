1A LIBRA - E-Commerce Web Application 
Full Stack web application developed for the management and simulation of purchases in an online store. The project integrates a clean, interactive frontend focused on user experience alongside a structured backend for data persistence and dynamic management.

Project Status: Work in Progress


Frontend: Modern and responsive interface structured with HTML5, custom CSS3 styling, and client-side dynamic interactivity using JavaScript (DOM manipulation and Fetch API).
Backend: Server built with Node.js for business logic processing and routing.
Database: Relational SQL database architecture for the storage and structured querying of catalogs and transactions.
Version Control: Modular source code management using Git and GitHub.
